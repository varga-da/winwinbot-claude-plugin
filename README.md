# Плагин WinWinBot для Claude

Конструктор ботов WinWinBot в вашей нейросети. Плагин подключает MCP-сервер платформы и добавляет эксперта: он проектирует ботов под бизнес, строит воронки и прогревы, пишет тексты под мессенджер, разбирает просадки и сам собирает бота инструментами кабинета — с теми же правами и подтверждениями, что у владельца.

Работает с Telegram, VK, MAX и Одноклассниками. MCP-сервер доступен на тарифе «Корпоративный».

## Что внутри

| Часть | Что делает |
|---|---|
| MCP-сервер `winwinbot` | инструменты кабинета: сценарии, меню, рассылки, товары, курсы, подписчики, статистика, проверка бота |
| Скилл `winwinbot` | архитектор ботов, маркетолог и аналитик; методику берёт из справочника платформы на сервере |
| `/winwinbot:new-bot` | спроектировать и собрать бота с нуля: бриф, проект, сборка, проверка |
| `/winwinbot:audit` | полный разбор бота и план улучшений по важности |
| `/winwinbot:funnel` | воронка или прогрев под продукт — проект и сборка |
| `/winwinbot:diagnose` | почему просели подписки, вовлечённость или продажи |
| `/winwinbot:content-plan` | контент-план рассылок по сегментам с текстами |
| `/winwinbot:launch-check` | проверка перед запуском трафика |

## Установка в Claude Code

```bash
claude plugin marketplace add varga-da/winwinbot-claude-plugin
claude plugin install winwinbot@winwinbot
```

Внутри сессии Claude Code то же самое — `/plugin marketplace add varga-da/winwinbot-claude-plugin` и `/plugin install winwinbot@winwinbot`. Обновление — `claude plugin marketplace update winwinbot`.

Из локальной копии репозитория:

```bash
claude --plugin-dir ./winwinbot
```

## ChatGPT, Cursor и другие MCP-клиенты

Плагин — формат Claude. В остальных клиентах подключите MCP-сервер по адресу `https://my.winwinbot.com/api/mcp` со входом через OAuth: экспертиза (справочник по проектированию ботов, воронкам и маркетингу) приходит с самого сервера.

При первом обращении к серверу откроется вход в кабинет WinWinBot: войдите и разрешите доступ («Полный» — собирать и править, «Только чтение» — советовать и разбирать). Проверка: в `/mcp` сервер `winwinbot` в статусе connected.

Вместо входа можно подключиться ключом из кабинета («Настройки → Токены API»): сервер `https://my.winwinbot.com/api/mcp`, заголовок `Authorization: Bearer <ключ>`.

## Безопасность

- Удаление, рассылка и сообщения живым подписчикам, деньги и массовые правки не выполняются без вашего явного подтверждения в разговоре.
- Токен бота, ключи платёжных систем и пароли плагин не спрашивает и не принимает — это шаги в кабинете, плагин подскажет, куда нажать, и проверит результат.
- Все правки пишутся в журнал действий бота; перед крупной переделкой создаётся точка восстановления.
- Доступ отзывается в настройках аккаунта в любой момент.
