Задача: контент-план рассылок бота WinWinBot. Вводные: $ARGUMENTS

Работай по скиллу `winwinbot`:

1. Пачкой: `get_bot_snapshot`, `get_audience_stats`, `get_content_engagement`, `list_broadcasts`, `list_segments`, `get_playbook` по разделам marketing и analytics. Площадка MAX рассылок не поддерживает — там только сценарии и триггеры.
2. Сегменты: кто купил, кто интересовался и не купил, новые, спящие. Охват каждого — `count_segment`.
3. План: таблица «дата — сегмент — цель письма — тема — призыв и кнопка». Чередуй пользу, кейсы, продажу; не чаще, чем база выдерживает без всплеска отписок.
4. Тексты первых сообщений плана — под мессенджер: коротко, одна мысль, одна кнопка.
5. По согласию: недостающие сегменты `create_segment`; рассылки — только тремя шагами с подтверждением владельца (`preview_broadcast_audience` → `send_test_broadcast` → `send_broadcast`). Предложи A/B первого сообщения.
